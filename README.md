# FrigeFood — Frontend

## Установка и запуск

```bash
npm install
```

Фронт откроется на `http://localhost:5173`

## Порядок запуска

1. Сначала запусти Redis
2. Затем запусти бэк (`mvn spring-boot:run`)
3. Затем запусти фронт (`npm run dev`)
4. Открой `http://localhost:5173`

## Страницы

| Страница | URL | Доступ |
|---|---|---|
| Вход | /login | Все |
| Регистрация | /register | Все |
| Холодильник | / | Авторизованные |
| Рецепты | /recipes | Авторизованные |
| Избранное | /favorites | Авторизованные |
| Профиль | /profile | Авторизованные |
| Админ-панель | /admin | Только ADMIN |
